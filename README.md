# Three Realms

A work-in-progress expansion for Heroes of Might & Magic III on [VCMI](https://vcmi.eu) (1.7 or newer).
It adds three factions, each with seven creature lines, heroes, a town screen and a few spells:

- **Pagoda**
- **Sepulcher**
- **Mycelium**

## Install

Copy this folder to `Documents\My Games\vcmi\Mods\threerealms` (so that `mod.json` is directly inside it),
then enable "Three Realms" in the VCMI launcher. You need your own copy of Heroes III; no other mods are required.

## Status

Playable but unpolished. The art is AI-generated and several parts are still placeholders.
